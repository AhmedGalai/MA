================================================================================

METHOD 1 - Direct Python (from Kubuntu directory):
   $ python3 debug_viewer.py

METHOD 2 - Using startup script:
   $ ./start_debug_viewer.sh

METHOD 3 - With custom API URL:
   $ python3 debug_viewer.py --api-url http://192.168.1.100:8000

METHOD 4 - Run examples:
   $ python3 example_debug_session.py --example minimal

================================================================================
                      SYSTEM REQUIREMENTS
================================================================================

Before running:
1. main_api.py must be running:
   $ python3 main_api.py

2. RealSense camera must be connected (optional for status viewing)

3. API must be accessible on configured host/port (default: 127.0.0.1:8000)

================================================================================
                       TROUBLESHOOTING
================================================================================

CONNECTION FAILED:
  ✓ Ensure main_api.py is running
  ✓ Check that host/port are correct
  ✓ Test connectivity: curl http://127.0.0.1:8000/health

NO REALSENSE:
  ✓ Check physical camera connection
  ✓ Verify pyrealsense2 installation
  ✓ Check API logs

NOT CALIBRATED:
  ✓ Run RealSense calibration via API
  ✓ Check ArUco board visibility
  ✓ Verify calibration file exists

SLOW UPDATES:
  ✓ Reduce refresh rate (try 1-2 Hz)
  ✓ Check API server CPU/memory
  ✓ Verify network latency

TKINTER ERRORS:
  ✓ Ensure tkinter installed: apt-get install python3-tk
  ✓ Verify X11 available (WSL2: start XServer)
  ✓ Test: python3 -m tkinter

================================================================================
                       API ENDPOINTS
================================================================================

GET /health
  Returns: {"status": "ok", "rs_connected": true, "calibrated": true}
  Used for: System status, connection verification

Polling Rate: Configurable via refresh slider (1-10 Hz)
Timeout: 3 seconds per request
